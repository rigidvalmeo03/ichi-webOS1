Hi! Welcome to “Chemistry.exe - Ichi's Digital Laboratory”
It is a tiny digital space dedicated to chemistry, curiosity, and fun pink stuff.

>About the Project
-Chemistry.exe is a personal chemistry-themed website created as part of the NASA Stardance Challenge.
-The website is designed as a small digital laboratory where visitors can explore chemistry notes, the periodic table, chemistry topics, learning resources, and an interactive chemistry quiz. I wanted to combine my interest in chemistry with a fun and personal web design, so I created the website to look like a small desktop environment with different chemistry applications.
-This project was also an opportunity for me to practice HTML, CSS, and JavaScript.

>Live Website
https://rigidvalmeo03.github.io/ichi-webOS1/
The website is hosted using GitHub Pages.

>Features
1. Chemistry Notes - this application contains basic chemistry information and quick facts.
Topics included:
Matter
Pure substances
Elements
Compounds
Mixtures
Atoms, molecules, and ions
Electronic structure
Pauli Exclusion Principle
Hund's Rule
Aufbau Principle
Chemical bonding
-The application also includes images related to Hund's Rule and the Aufbau Principle.

2. Periodic Table - this application contains information about elements and periodicity.
It includes:
Common elements and their atomic numbers
A periodic table image
Periodicity
Atomic radius
Ionization energy
Electronegativity
Metallic character
Periodic table groups and families

The groups covered include:
Alkali Metals
Alkaline Earth Metals
Transition Metals
Boron Group
Carbon Group
Nitrogen Group
Oxygen Group
Halogens
Noble Gases

3. Chemistry Quiz - this app is an interactive multiple-choice chemistry quiz.
It currently includes five questions about:
Chemical symbols
Atomic numbers
Chemical formulas
Subatomic particles
pH

The quiz includes:
Four answer choices per question
Instant answer feedback
Correct-answer highlighting
Score tracking
Next Question button
Final score
Restart Quiz button

The quiz was created using JavaScript arrays, functions, conditionals, and DOM manipulation.

4. Interactive Windows - The chemistry applications open inside their own windows.
The windows can:
Be opened
Be closed
Be dragged around the page
-The website also includes a live clock in the top bar.

5. Chemistry Resources
The website contains a collection of chemistry-related learning resources and YouTube channels, including:

>How to Use
-No installation is required to use the website. Simply visit:
https://rigidvalmeo03.github.io/ichi-webOS1/

Once inside the website:
1. Click the Chemistry Notes icon to open the chemistry notes.
2. Click the Periodic Table icon to explore elements and periodicity.
3. Click the Chemistry Quiz icon to start the quiz.
4. Choose an answer for each question.
5. Read the feedback after answering.
6. Click Next Question to continue.
7. View your final score after completing the quiz.
8. Click Restart Quiz if you want to try again.
The application windows can also be dragged around the page.

>Viewing the Project Locally
To view or edit the project locally:
1. Download or clone this repository.
2. Keep all of the project files in the same folder.
3. Open index.html in a web browser.

The project should contain:
index.html
script.js
aufbau-principle.png

-No additional packages or installations are required.
